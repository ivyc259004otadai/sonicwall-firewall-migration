# SonicWall ファイアウォール設定移行・疎通検証

## 概要

学校施設のファイアウォール更改に伴い、SonicWall NSa2650からNSa2800への設定移行と疎通検証に参加しました。

担当教員の管理・指導のもと、既存設定の確認、アクセスルールの手動移行、機器切替、通信障害の原因調査を経験しました。

## 担当した作業

- 既存のアクセスルールの確認・整理
- 新機器へのアクセスルールの手動移行
- 担当教員との設定レビュー
- 機器切替作業への参加
- 切替後の疎通確認
- 通信障害に対する原因調査・検証

## 使用機器・関連技術

- SonicWall NSa2650 / NSa2800
- Firewall / Access Rules
- NAT / DNS
- LAN / WAN / DMZ
- ネットワーク疎通検証

## 検証結果と学び

初回切替後の疎通確認では問題を検出できませんでしたが、翌朝の通常利用時に通信障害が発生しました。

旧機器への切り戻し後、担当教員とともにアクセスルールやNAT、DNS通信などを調査しました。最終的な復旧対応は担当教員が実施しました。

この経験から、pingによる疎通確認だけでは利用者の正常な通信を保証できず、名前解決やWebサイトの閲覧確認を組み合わせる重要性を学びました。
